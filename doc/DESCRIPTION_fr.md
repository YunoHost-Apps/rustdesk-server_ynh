Auto-hébergez votre propre serveur RustDesk. RustDesk est une alternative de contrôle à distance open source complète pour l'auto-hébergement et la sécurité avec une configuration minimale.

Elle utilise uniquement ses propres ports réseau (TCP 21115-21119, UDP 21116) : elle ne réserve aucun domaine ni chemin web, des applications web peuvent donc toujours être installées sur tous les domaines.
